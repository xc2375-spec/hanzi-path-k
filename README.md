# 汉字学习路径 · Hanzi Learning Path

面向成人初级汉语学习者的汉字学习自测网站。学习顺序由多条件动态贪心算法生成（字频、部件、词汇生成力、声旁、构式、句框、可学性），每个字附带解锁词。界面说明为英文，支持简体／繁體一键切换。

A self-paced web app for adult beginning CSL learners. The 500-character sequence is generated by a multi-criteria dynamic greedy algorithm (frequency, components, lexical productivity, phonetic series, constructions, sentence frames, learnability). All UI text is in English, with a one-click Simplified / Traditional toggle.

## Features

- **Learn** — flashcards with rice-grid (米字格) display, pinyin, English gloss, components, and words unlocked by each character
- **Quiz** — 10-question rounds (pinyin or meaning, multiple choice), drawn from learned characters
- **Progress** — three-stage progress bars (A: 1–50, B: 51–200, C: 201–500), quiz history
- **Progress data stays in the student's own browser** (localStorage) — no account, no server

## Deploy to GitHub Pages（最简方式 · no Actions）

仓库里已经带了一份**构建好的页面**（`docs/` 文件夹），GitHub 不需要任何构建步骤，所以不会出现空白页：

The repo already contains a **pre-built page** (the `docs/` folder). GitHub serves it as-is — nothing is built on GitHub's side, so the blank-page problem disappears.

1. 把整个仓库推上 GitHub 的 `main` 分支（**连同 `docs/` 文件夹一起**）：
   ```bash
   git init
   git add .
   git commit -m "hanzi learning path"
   git branch -M main
   git remote add origin https://github.com/你的用户名/hanzi-path-app.git
   git push -u origin main
   ```
2. 打开仓库页面 → **Settings** → 左侧 **Pages**
3. 在 **Build and deployment** 下：
   - **Source** 选 **Deploy from a branch**
   - **Branch** 选 **main**，文件夹选 **/docs**，点 **Save**
4. 等 1–2 分钟，页面就在 `https://你的用户名.github.io/hanzi-path-app/` 上线

> 注意：`docs/.nojekyll` 这个空文件很重要，不要删除（它告诉 GitHub 跳过 Jekyll 处理，否则 `_` 开头的文件会被忽略）。

## Update the content

改了内容之后重新构建并更新 `docs/`：

```bash
npm install
npm run build
rm -rf docs && cp -r dist docs && touch docs/.nojekyll
git add -A && git commit -m "rebuild" && git push
```

## Run locally

```bash
npm install        # first time only
npm run dev        # dev server
# or preview the production build:
npm run build && npx serve docs
```

## Tech stack

React 18 + TypeScript + Vite + Tailwind CSS. The 500-character dataset (`src/data.json`) is derived from CJKVI-IDS, Unihan, SUBTLEX-CH, Jun Da's Modern Chinese Character Frequency List, HSK 3.0 wordlist, and CC-CEDICT.
